# YC Power privacy

YC Power changes cloud navigation in the console. It does not manage cloud resources, collect analytics, or send settings to a server.

The extension reads the cloud and folder names, IDs, organization groups, and links already rendered by the console. It uses them to build the sidebar. Expanding a cloud uses the console's existing controls and requests.

Selected cloud IDs and their order, custom labels, colors, folder icons, sidebar width, and display preferences are stored in the extension's local browser storage, separately for each federation, organization, and console origin. A local cache of cloud and folder names, IDs, organization groups, and console links lets the sidebar display previous results while refreshing them in the background. The configured list of console addresses, per-address clouds-only mode, organization collapse state, and compact-mode preference are also stored locally. These settings are not synchronized to a developer service.

The extension reads the active federation ID and name from the console's JSON bootstrap data. Federation IDs and names are cached locally to group navigation. Only the current federation is refreshed; other federations use their local cache. The personal account heading stores the Yandex account display name, or its login when a display name is unavailable. The numeric passport UID is used only to recognize the account type and is not saved. A separate snapshot identifies catalogs collected under a verified Yandex account. An optional display setting combines those organizations with federation groups, using only cached data for the inactive account mode. The personal account subject ID from the console bootstrap is cached locally to select that account through the console’s native account-switch route. It is not a credential or the numeric passport UID. Older caches without this ID open the native account picker until the personal account has been visited again. Opening a cached federation resource starts the console's federation sign-in flow. A destination link is held in this tab's session storage for up to five minutes and removed after sign-in to the matching account. The extension does not read authentication cookies or save credentials. Previous settings without a federation remain intact and can be copied explicitly into the current federation.

You can export settings and the local navigation cache to a JSON file and import that file in another browser. The file includes configured console addresses, cloud and folder names and IDs, and customization preferences. Export and import happen only when you choose them; the extension does not upload the file to a server. Browser permissions for imported console addresses are requested when you save the imported settings.

The default permission covers only `https://console.yandex.cloud`. Additional HTTPS origins require the browser's permission when you save them. Removing a custom origin revokes its optional permission. An empty list disables the extension everywhere.

The sidebar follows the console language. Extension settings use the browser interface language, then the system language, with English as the fallback. Russian and English are supported.
